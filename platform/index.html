Mechanism

Guidance that removes itself

SHOW

Point, don't take over

Disha reads the live page — every button, link and field with its accessible name — and marks the single next step. You do the clicking. It never types your password or presses submit.

CHECK

Admit doubt honestly

The colour isn't the AI's opinion of itself. Disha independently scores the page evidence, and the model and the page must agree before a dot turns green.

FADE

Then get out of the way

Every time you complete a step yourself the guidance dims. Get it wrong and the help returns. Mastery is earned, and it can be lost.

Setup

Install in one minute

chrome://extensions

Browsers block web pages from opening chrome:// addresses directly — a security rule, not an oversight. Copy it and paste it into your address bar.

In the popup, leave the provider on Local model. Disha then runs entirely on your machine — no key, no account, and nothing about the page you are on leaves it.

  1. Paste the address above into a new tab and press Enter.
  2. Turn on Developer mode (top-right toggle).
  3. Click Load unpacked (top-left).
  4. Select the prototype/guide-dots folder from this project.
  5. Click the 🧩 puzzle icon and pin Disha to your toolbar.
  6. Open the practice portal and run the three tasks there.

Why this is different

Four things nothing else combines

Confidence you can see

Every dot carries a number the system can be held to, computed from the page itself — not a model marking its own homework.

It guides; it never acts

The human always clicks. That is what makes it safe on a portal handling money, identity or an exam form.

Works where nobody scripted it

Existing walkthrough tools need every step authored in advance. Disha reads whatever is on screen, so a redesign doesn't break it.

Teaching, not a shortcut

Active learning raised performance by 0.47 SD across 225 studies. Fading guidance is how that becomes software.

What we don't claim. Microsoft Copilot Vision already highlights where to click, and we did not invent AI screen understanding. What no shipped product combines is calibrated, visible confidence, guidance that fades on demonstrated mastery, and task packs built for Indian student and public-service portals.
