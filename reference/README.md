# reference/ — material we did not write

**Everything in this folder is gitignored except this file.** That is deliberate.

None of it is our work. All of it can be downloaded again in a few minutes. It is
roughly 23 MB of PDFs and Office files that a teammate cloning this repo does not
need in order to run, understand or present Disha — so the repo carries our
product, and this folder carries our source material.

This is the same rule that applied to `borrowed/`, the 272 MB of third-party repos
that were reference-only and were deleted once each had earned its keep (see
[`../ATTRIBUTION.md`](../ATTRIBUTION.md)).

**If your clone has an empty `reference/`, that is correct.** Refill it from the
table below only if you actually need to read one of these.

## ⚠️ Two things not to get wrong

1. **The template in here is the 2024 edition.** The official rules say to use *the
   provided* template, so download the **2026** file from the SIH portal and paste
   our text into that one. The section structure is unchanged between editions, so
   nothing in `deck/slides.md` needs rewriting — but the logo, the year and the
   footer must come from the 2026 file.
2. **`past winning teams/` is a misleading folder name.** Only one of the three is
   a real team's deck. See the table above before citing anything from it.
